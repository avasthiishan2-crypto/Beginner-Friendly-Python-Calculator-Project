# 🧮 Python Menu-Driven Calculator

This is a simple command-line calculator built using Python. It allows users to perform basic arithmetic operations in a continuous loop until they choose to exit.

## 🚀 Features
- Addition, Subtraction, Multiplication, Division
- Average calculation
- Continuous loop (no need to restart program)
- Error handling (invalid input & division by zero)
- User-friendly menu interface

## 🛠️ Technologies Used
- Python (Core Concepts)
- Functions
- Loops
- Exception Handling (try-except)

## 📌 How to Run
1. Install Python
2. Download or clone this repository
3. Open terminal in project folder
4. Run the file:

```bash
python calculator.py
